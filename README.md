# 个人记录

一个手机优先、电脑也能使用的极简个人打卡日历。使用原生 HTML、CSS、JavaScript，无框架、无后端、无构建流程，运行时不加载第三方统计、外部字体或图表库。

核心操作是：**点击打卡记录当前时间，在日历中查看历史记录**。支持同日多次记录、历史补签、确认删除，以及周／月／年图表统计。数据仅保存在当前浏览器，不登录、不上传、不跨设备同步。

## 本地运行

推荐在项目目录启动静态文件服务，需要本机安装 Python：

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:5173`。后续请使用相同的浏览器配置、协议、地址和端口访问，以读取原来的记录。按 `Ctrl+C` 停止服务。

也可以用现代浏览器直接打开 `index.html`，但不同浏览器对本地文件存储的处理可能不同，因此更推荐使用上面的本地服务。

页面运行和部署不需要 Node.js；Node.js 只用于可选的测试。

## 日历与打卡

- **月历导航**：默认显示本月，以周一为每周起点，固定六行七列；支持上个月、下个月和返回今天。
- **日期状态**：今天显示描边，所选日期显示浅色背景。有记录的日期显示飞机图标；当前月的图标为绿色，相邻月份的日期及飞机图标均弱化为灰色。
- **查看记录**：点击任意日期，打卡按钮下方显示该日期的记录，时间格式为 `HH:mm:ss`，最新记录在前。没有记录时显示「这天还没有记录」。
- **相对日期**：所选日期标题右侧显示相对今天的天数，例如「（10天之前）」「（3天之后）」，今天显示「（今天）」。按设备本地日历日期计算，而不是按经过了多少个 24 小时计算，支持跨月、跨年、闰年及夏令时切换。
- **记录当前时间**：点击「打卡 · 记录当前时间」保存点击时的实际时间，并自动返回今天所在的月份和日期。浏览过去或未来日期，不会改变普通打卡的记录时间。
- **防止误触**：保存期间及成功后短暂禁用打卡按钮，成功后的禁用时间为 1.5 秒，随后允许继续记录。同一天可以有多条记录。
- **删除记录**：每条记录提供删除入口，确认后才删除。删除某天的最后一条记录后，该日期的飞机标记会消失。
- **跨午夜**：页面会定时检查日期，回到窗口或恢复页面可见时也会检查。原先查看今天时跟随新今天；查看其他日期时保留选择，并更新相对天数提示。打卡时始终重新获取当前时间。

页面采用暖白背景、深灰文字和低饱和绿色，单列居中布局。左上角标题为「个人记录」，不带装饰点；补签按钮与旁边记录数使用相同的字号、高度、内边距和圆角，保持紧凑。

## 历史补签

在日历中选择过去的日期，点击记录标题右侧的「＋ 补签」，填写实际发生的时间后确认。时间精确到分钟，秒数保存为 `00`，不预填默认时间。

- 今天和未来日期不显示补签入口；绿色打卡按钮始终记录当前时间。
- 一天可以补签多条，按实际发生时间倒序排列，并显示「补签」标记。
- 保存后停留在所选日期；取消不保存，保存失败会保留输入以便重试。
- 补签属于新增历史记录，不提供已有记录的时间编辑或批量管理。
- 使用原有存储键，补签记录增加 `source: "manual"` 字段；旧记录无需迁移，按正常打卡显示。

## 图表统计

点击页面右上角「统计」进入独立视图，点击「返回记录」回到原先选择的日历日期，不挤占首页打卡空间。

- **周／月／年**：默认本月。周从周一开始；可以查看上一周期、下一周期和返回当前周期，不进入未来周期。
- **统计概览**：记录次数、有记录天数、日均次数。同一天的多条记录分别计次，有记录天数只计一天。
- **日均口径**：历史周期按完整日历天数计算；当前周期按开始至今天的天数计算（含今天），不以有记录天数为分母。
- **次数图表**：周展示 7 天、月展示 28–31 天、年展示 12 个月。点击柱子或使用下方选择框查看具体次数和补签数量；未来日期以斜纹区分。
- **时间分布**：按本地时间分为凌晨（00:00–05:59）、上午（06:00–11:59）、下午（12:00–17:59）、晚上（18:00–23:59）。
- **补签归属**：按记录实际发生时间归入对应周期，而不是补签操作当天。晚于实际当前时间的记录不提前计入统计。
- **自动更新**：新增、补签、删除成功后重新汇总；同源其他标签页的存储变化也会更新。
- **异常状态**：没有记录时显示空状态；无法读取存储时显示「统计暂不可用」，不会误显示为零次。不保存额外统计数据。

## 项目结构

```text
index.html          页面结构、记录视图、统计视图和确认对话框
styles.css          响应式布局、日期状态、飞机标记和图表样式
calendar.js         本地日期、相对天数、月历、记录校验及存储基础逻辑
statistics.js       周／月／年周期与统计汇总纯函数
statistics-view.js  统计视图渲染、周期导航及图表交互
app.js              日历、打卡、补签、删除及跨午夜刷新的交互控制
README.md           使用、数据、部署和测试说明
```

HTML 和 JavaScript 包含中文注释。`calendar.js` 与 `statistics.js` 同时支持浏览器使用及 Node.js 测试，无需打包。

## 数据与隐私

- 记录写入当前浏览器的 `localStorage`，键为 `personal-records.v1`，值为 JSON 数组，不向服务器上传。
- 每条记录包含唯一标识 `id` 和毫秒时间戳 `timestamp`；补签记录带有 `source: "manual"`。普通记录可以不包含 `source`，兼容旧数据。
- 日期划分与时间显示使用设备当前本地时区；改变时区后，同一条记录可能归入不同日期。
- **不同设备、不同浏览器或不同浏览器配置之间不共享记录**。即使访问同一个部署地址，电脑与手机中的数据也各自独立。
- 同一浏览器配置下，存储按来源区分：协议、主机名、端口任一不同，都不会自动共享记录。例如本地服务与线上域名的数据互不相通。
- 同源的其他标签页修改记录时，当前页面会重新读取并刷新；这不是跨设备同步。
- 清除浏览器数据、结束无痕会话或浏览器清理存储，可能导致记录丢失。此版本没有账户、同步、导入导出或自动备份功能。
- 本地存储不是加密保险箱：共用同一浏览器配置的人可以查看记录。
- 无法读取或解析已有数据时，禁止新增、补签及删除，不自动用空数据覆盖原始内容；保存失败时显示错误，不展示虚假的成功状态。

页面底部提示：「记录仅保存在当前浏览器，清除浏览器数据后会丢失。」

## 静态部署与更新

这是纯静态页面，无需 Node.js 服务、后端、数据库或构建步骤。部署到静态托管服务时，需要将以下 **6 个运行文件**放在同一目录并完整上传：

```text
index.html
styles.css
calendar.js
statistics.js
statistics-view.js
app.js
```

- 不要遗漏脚本，也不要只更新 HTML；页面依赖这六个文件的配套版本。
- `.idea/`、`.playwright-cli/`、`output/` 和本地 `tests/` 不属于运行文件，不需要部署。
- 使用 GitHub 作为部署来源时，需先将本地修改提交并推送到部署所使用的分支；只修改本地文件不会更新线上页面。
- 更新代码不会主动清除已有记录。在相同浏览器配置和来源下访问，仍会尝试恢复原有记录；更换域名、协议或端口后不会自动迁移。
- 用户的打卡记录不会随代码提交到 GitHub，也不会因部署更新而在不同设备间同步。

## 测试与验收

> 当前 `.gitignore` 排除了 `tests/`，测试脚本仅保存在本地，默认不会随 Git 推送。以下自动化命令仅适用于已包含这些脚本的工作目录；新克隆的仓库可先进行下方的手动验收。

### 单元测试（本地可选）

需要 Node.js，无需安装项目依赖：

```powershell
node --test tests/calendar.test.cjs tests/statistics.test.cjs tests/relative-date.test.cjs
```

覆盖周一起始月历、闰年与跨年、本地日期与午夜、多条记录排序、数据校验、存储错误、补签日期时间校验及旧数据兼容，以及相对日期、夏令时、统计周期边界、分时段计数、补签归属和日均口径。

### 浏览器自动验收（本地可选）

先启动上述本地服务，并确保 Node.js、npm 和所需浏览器可用。`npx` 可能需要联网下载测试工具，页面本身没有这项运行依赖。

以下命令使用独立的测试浏览器会话；部分脚本会清空该测试会话中本页面的记录。**不要连接到日常使用的浏览器会话运行这些脚本。**

```powershell
npx --yes --package @playwright/cli playwright-cli -s=record-check open http://127.0.0.1:5173
npx --yes --package @playwright/cli playwright-cli -s=record-check run-code --filename tests/browser-check.js
npx --yes --package @playwright/cli playwright-cli -s=record-check run-code --filename tests/backfill-browser-check.js
npx --yes --package @playwright/cli playwright-cli -s=record-check run-code --filename tests/statistics-browser-check.js
```

### 手动验收

1. 首次打开显示本月和今天，空记录列表布局完整。
2. 点击打卡出现当前时间和飞机标记，刷新后记录仍在；快速连点不会意外生成多条记录。
3. 点击过去、今天和未来日期，检查日期标题右侧的相对天数；相邻月份日期的飞机图标应为灰色。
4. 浏览其他日期时点击打卡，仍记录实际当前时间，并返回今天。
5. 选择过去日期进行补签，确认记录显示「补签」标记，时间和日期正确。
6. 删除先弹出确认框；取消不变，确认才删除，最后一条删除后日期标记消失。
7. 切换周／月／年统计，检查次数、有记录天数、日均和补签归属。
8. 检查窄屏无横向滚动，补签入口与记录数尺寸一致，日历和主打卡按钮保持紧凑。
